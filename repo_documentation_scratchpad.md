# Repository Documentation                                                                                                                                                                                        
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 ## Overview                                                                                                                                                                                                       
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 This repository contains code for generating and displaying GIF data based on user stories. The core functionality revolves around processing user stories, generating image data using a generative AI model, an 
 then displaying this data.                                                                                                                                                                                        
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 ## Key Features                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 - **User Story Management:** The application reads user stories from `user_stories.txt`, processes them, and updates their status.                                                                                
                                                                                                                                                                                                                   
 - **Image Generation:** It uses the Gemini AI model to generate base64 encoded image data based on the user story.                                                                                                
                                                                                                                                                                                                                   
 - **Image Storage:** The generated image data is stored in `image_database.txt`, associated with the user story ID.                                                                                               
                                                                                                                                                                                                                   
 - **Real-time Display:** The application uses WebSockets to send the generated image data to connected clients for real-time display.                                                                             
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 ## File Structure                                                                                                                                                                                                 
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 - `index.js`: This is the main application file. It handles reading user stories, generating images, updating statuses, and sending data to clients via WebSockets.                                               
                                                                                                                                                                                                                   
 - `archive/database_manager_agent.js`: This file contains similar functionality to `index.js` but is not currently used.                                                                                          
                                                                                                                                                                                                                   
 - `user_stories.txt`: This file stores the user stories, including their ID, description, tags, and status.                                                                                                       
                                                                                                                                                                                                                   
 - `image_database.txt`: This file stores the generated image data, associated with user story IDs.                                                                                                                
                                                                                                                                                                                                                   
 - `public/`: This directory contains static files for the web client.                                                                                                                                             
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 ## Core Logic                                                                                                                                                                                                     
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 1.  **Read User Stories:** The application reads user stories from `user_stories.txt`.                                                                                                                            
                                                                                                                                                                                                                   
 2.  **Find Pending Story:** It identifies the next user story with a "Pending" status.                                                                                                                            
                                                                                                                                                                                                                   
 3.  **Update Status:** The status of the selected user story is updated to "In Progress".                                                                                                                         
                                                                                                                                                                                                                   
 4.  **Generate Images:** The Gemini AI model generates two base64 encoded images based on a prompt.                                                                                                               
                                                                                                                                                                                                                   
 5.  **Update Status:** The status of the user story is updated to "Done".                                                                                                                                         
                                                                                                                                                                                                                   
 6.  **Store Images:** The generated images are stored in `image_database.txt`.                                                                                                                                    
                                                                                                                                                                                                                   
 7.  **Send Data to Client:** The generated image data and the user story ID are sent to connected clients via WebSockets.                                                                                         
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 ## Important Considerations                                                                                                                                                                                       
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 -   The application uses a polling mechanism (`setInterval`) to check for new user stories every 10 seconds.                                                                                                      
                                                                                                                                                                                                                   
 -   The Gemini API key is loaded from the environment variable `GEMINI_API_KEY`.                                                                                                                                  
                                                                                                                                                                                                                   
 -   The application uses `node-fs/promises` for asynchronous file operations.                                                                                                                                     
                                                                                                                                                                                                                   
 -   The application uses `express` for serving static files and `ws` for WebSocket communication.

 ## Focus Feature: Real-time GIF Data Assembly and Display                                                                                                                                                         
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
                                                                                                                                                                                                                   
 The core feature of this application is the real-time assembly and display of GIF data. The application generates base64 encoded image data, which is then sent to the client via WebSockets. The client can then 
 use this data to assemble and display the GIF. This feature is crucial for providing a dynamic and interactive experience.
